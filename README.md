# The Modder v2 (Fabric 1.21.1)
Mod de poderes e habilidades (RPG) com efeitos visuais pesados. Requer Java 21 + Fabric Loader + Fabric API.

Compilar: suba esta pasta num repositório do GitHub -> aba Actions -> baixe o .jar em "Artifacts".
Ou localmente com Gradle 8.10+: `gradle build` (jar em build/libs/).

Teclas: R usa o poder, V troca, K abre o menu.
Comandos: /modder, /modder fx <1-3> (qualidade dos efeitos), /modder xp <n> (OP).

Poderes: Raio Veloz, Dragão de Fogo, Aura Sagrada, Tempestade, Barreira Arcana, Terremoto, Meteoro, Tornado.
Terremoto, Meteoro e Tornado mexem no terreno (blocos viram blocos caindo). Com mobGriefing desligado, o terreno não é afetado.
